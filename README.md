📝 To-Do List Application
📌 Description

A simple Python-based To-Do List application that allows users to add, view, and delete tasks using a console interface. This project demonstrates basic programming concepts and helps improve productivity.

🚀 Features
➕ Add new tasks
📋 View all tasks
❌ Delete tasks
⚠️ Handles invalid input
🔁 Continuous menu-driven program
🛠️ Technologies Used
Python (Core concepts)
